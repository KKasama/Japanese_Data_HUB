Significance & Distribution Strategy意義と配信戦略

Distribution Hub: OpenAlex Public Infrastructure 配信ハブ：OpenAlexのパブリックインフラを活用
Rather than building a separate download platform, Japanese Data Hub routes all data through OpenAlex — the open scholarly index. OpenAlex publishes data via API (api.openalex.org) and S3 Snapshot (s3://openalex), which Unpaywall, LENS, Semantic Scholar, and institutional repositories already consume. One ingestion point → global reach. 独自のダウンロードプラットフォームを構築するのではなく、Japanese Data HubはすべてのデータをOpenAlex（オープン学術インデックス）経由で配信します。OpenAlexはAPI（api.openalex.org）とS3スナップショット（s3://openalex）でデータを公開しており、Unpaywall・LENS・Semantic Scholar・機関リポジトリはすでにそこから取得しています。一点投入 → グローバル配信。

⑤ Specialized専門機関
NIMS, JAEA, RIKEN, Ichushi-kai — critical for domain-specific harvesting services.NIMS・JAEA・RIKEN・いちょう会 — 分野特化型サービスへの提供に重要。
Strategic Goal:戦略目標： Japanese Data Hub harvests and normalizes JaLC metadata, then submits it to OpenAlex — the open scholarly index backed by AWS S3. Because Unpaywall, LENS, Semantic Scholar, and institutions already consume OpenAlex data, a single ingestion point achieves global distribution without building a separate platform. This is the most efficient path to making Japan's research ecosystem discoverable worldwide. Japanese Data HubはJaLCメタデータをハーベスト・正規化し、AWS S3に裏付けられたオープン学術インデックス「OpenAlex」に投入します。Unpaywall・LENS・Semantic Scholar・各機関がすでにOpenAlexデータを取得しているため、一点投入でグローバル配信が実現し、独自プラットフォームの構築は不要になります。日本の研究エコシステムを世界中で発見可能にする最も効率的な経路です。

jhub — Harvest Tool Overviewjhub — ハーベストツール概要

jhub is a Python-based internal tool that harvests JaLC metadata, normalizes it to OpenAlex format, and serves it via API. jhubはJaLCメタデータをハーベストし、OpenAlex形式に正規化してAPI経由で提供するPython製内部ツールです。

jhub Commandsjhub コマンド
Harvest from JaLCJaLCからハーベスト
python3 -m jhub harvest-jalc --site-id SI/JST.JSTAGE
Import converted file変換ファイルのインポート
python3 -m jhub import-jalc-file data.json
Ingest & serveインジェスト＆サーバー起動
python3 -m jhub ingest && python3 -m jhub serve
